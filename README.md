# MADE Madeira Design — Home v2

Home inicial em Next.js + TypeScript, usando fotos reais fornecidas pela empresa como portfólio provisório.

## Rodar
npm install
npm run dev

## Observação
Substituir as imagens em `public/images` pelas versões originais de maior resolução quando disponíveis. O link do WhatsApp no CTA usa o número informado anteriormente e deve ser confirmado antes do deploy.
