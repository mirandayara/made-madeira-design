# MADE Madeira Design — Home v3

Site em Next.js + TypeScript para a MADE Madeira Design.

## Estrutura
- `app/` — páginas e estilos
- `public/images/` — fotos tratadas do portfólio

## Rodar localmente
```bash
npm install
npm run dev
```

## Deploy
O projeto pode ser importado diretamente pela Vercel a partir do GitHub.
